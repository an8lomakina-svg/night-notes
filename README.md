# Night Notes

Статический персональный блокнот для GitHub Pages: задачи, планы, календарь, импорт `.ics`, голосовой ввод и озвучивание фокуса дня.

## Публикация на GitHub Pages

1. Создайте репозиторий, например `username.github.io`.
2. Загрузите в корень репозитория содержимое этой папки (не саму папку `night-notes`).
3. В GitHub: **Settings → Pages → Deploy from a branch → main / root**.
4. Откройте `https://username.github.io`.

## Синхронизация

Войди по email в профиле Night Notes один раз на каждом новом браузере или устройстве. После подтверждения записи автоматически загружаются при открытии блокнота и при возврате к вкладке; ссылки для переноса данных не нужны. Локальная копия остаётся в браузере как запасной вариант до первой синхронизации.

Для календаря используйте экспорт Google Calendar в `.ics` и кнопку «импорт .ics». Прямой Google Calendar sync требует отдельной OAuth-настройки Google Cloud и намеренно не имитируется в статической версии.

Голосовой ввод использует Web Speech API и лучше всего поддерживается в Chrome/Edge. Нажмите маленькую оранжевую кнопку возле поля новой задачи и произнесите её.
